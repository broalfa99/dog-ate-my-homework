## The entry

> I didn't eat your homework. I filed it. In my stomach. Forever.

One line, 63 characters — the excuse a dog gives after being caught eating
the homework. The joke turns on dog bureaucracy: the dog denies eating it,
then admits it "filed" the homework — in its stomach, forever. A dog who
believes it has done nothing wrong.

## How it works

`main.py` writes that single line to `/output/entry.txt`. It refuses to
write anything outside the competition gate (1–200 characters, one line),
so an invalid entry can never be submitted by accident. It also reads the
file back and checks the round-trip matches before finishing.

Run it with `python3 main.py`.
